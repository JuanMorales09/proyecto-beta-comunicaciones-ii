# Informe IEEE - Fase 2

- `Informe_Fase2_Grupo5.pdf`: version para entregar (formato IEEE a dos columnas).
- `Informe_Fase2_Grupo5.docx`: version editable en Word.
- `generar_informe.js`: script que genera el .docx a partir de las figuras de `results/figures/` y `docs/figuras/`
  (requiere Node.js y el paquete `docx`: `npm install docx` y luego `node generar_informe.js`).
